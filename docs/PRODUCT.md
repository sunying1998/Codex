# 产品范围与开发顺序

## 已确定的方向

- 名称暂定「映刻 YINGKE」，中文视频创作工作台。
- 先供所有者私人试用；效果和使用流程验证后面向中国大陆开放。
- 效果优先，收费方式在真实模型、分辨率、视频时长和重试成本验证后制定。
- 最终能力包括面部、整个头部、服装及整个人物替换，并支持后续自定义剪辑。
- AI 通过业务 API 接入，未来网站助手与 MCP 共用相同权限边界和任务接口。

## 里程碑一：个人内测基础

形成注册初始化 → 上传 → 创建项目 → 预览 → 选片 → 保存 → 导出 → 下载的真实闭环。数据跨刷新与服务重启保存，原素材保留，导出版本独立。后台具备取消、失败提示、去重及中断恢复。

当前实现采用单所有者、本地持久化，方便直接运行与验证。AI 入口明确显示未接入，不承诺不存在的效果。当前时间线支持一个源视频与一个导出范围，复杂多轨、转场、字幕、调色属于后续能力。

## 里程碑二：真实人物替换验证

从 5–10 秒、单人、仅面部替换开始，比较候选服务实际效果与处理成本。测试素材应覆盖正脸、侧脸、转头、唱歌、运动、遮挡和不同光线。

首版范围已明确：一张参考照片替换目标脸部身份，以保留原片的头发、身体、服装、背景、动作、表情、口型及音轨内容为目标。服务选择优先专用视频换脸能力，换装作为后续独立任务扩展。完整接入设计与样片标准见 [面部替换第一版](FACE_SWAP_V1.md)。当前尚未选定并接入真实供应商，普通导出不会改变人物外貌。

评估身份一致性、口型与表情保留、边缘融合、光影、帧间闪烁以及镜头间一致性。保存模型名称与版本、参考素材、参数、任务输入、结果和用量，支持对比与局部重做。确认实际身份控制能力、接口稳定性和素材处理规则后接入，凭据仅在安全配置中提供。

本阶段再实现模型任务的回调 / 轮询、取消、失败重试、供应商费用记录及下载结果校验。MCP 在稳定的业务 API 上提供受认证的工具，不直接暴露文件系统或密钥。

## 里程碑三：中国大陆公众版本

根据验证结果选择部署区域、模型、对象存储和支付服务。扩展多用户注册与恢复、账号管理、严格资源隔离、配额预占和结算、任务失败处理、计费及退款规则、运营后台、限流、告警和备份恢复。

上线前完成负载测试和目标地区网络验证，落实部署所需的备案、隐私说明、素材保存与删除规则、肖像授权和投诉处理。收费依据实测计算与存储成本制定，当前不虚构价格。

随后逐步加入换头、换装、全身替换、多人跟踪、跨镜头一致性和更完整的剪辑器。
